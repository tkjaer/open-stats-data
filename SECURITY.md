# Security

This repository holds data published by
[open-stats](https://github.com/tkjaer/open-stats): weekly visit-count JSON files
and GoatCounter settings snapshots written by its export. It has no code,
dependencies or workflows of its own.

## Reporting a problem

Please **don't open a public issue**. Report problems with the data (for
example numbers that could single out a visit, or a file that shouldn't be
there) and anything else security-related privately through
[open-stats' private vulnerability reporting](https://github.com/tkjaer/open-stats/security/advisories/new).
I'll reply as soon as I can and credit you in the fix unless you'd rather not be named.

## Supported versions

Only the current `main` branch is maintained.
